# ساعت جهانی فارکس | Forex World Clock

> ابزار رایگان نمایش زنده سشن‌های معاملاتی بازارهای جهانی فارکس با تایم‌لاین همپوشانی، نمودار نوسان ساعتی و هشدار باز/بسته شدن بازارها.

🌐 **سایت زنده**: [razoromooz.github.io/sessions](https://razoromooz.github.io/sessions/)

## ✨ امکانات

- 🕐 **نمایش زنده ساعات ۵ بازار جهانی**: سیدنی، توکیو، لندن، نیویورک، تهران
- ⚡ **تایم‌لاین همپوشانی بازارها**: شناسایی ساعات پرنوسان (High Volatility Zones)
- 📊 **نمودار نوسان ۲۴ ساعته**: نمایش حجم معاملات در هر ساعت
- 🔔 **هشدار صوتی**: نوتیفیکیشن باز و بسته شدن بازارها
- 💱 **جفت‌ارزهای فعال**: نمایش مهم‌ترین جفت‌ارزهای هر بازار
- 📅 **تاریخ شمسی و میلادی**: نمایش همزمان دو تقویم
- 🌙 **حالت شب و روز**: تم تیره و روشن
- 🎨 **شخصی‌سازی کامل**: تغییر رنگ‌ها، تم‌ها و پس‌زمینه
- 📱 **واکنش‌گرا**: سازگار با موبایل، تبلت و دسکتاپ
